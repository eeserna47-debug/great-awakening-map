# About This Vault

## What this is

A knowledge-graph reconstruction of the *Great Awakening Map*, a 2018 poster by artist Parinya Champ (studio name "Art House"), sold as wall art and widely shared in QAnon-adjacent and New Age "awakening" communities. The original is a single dense illustration; this vault breaks its major visual clusters into individual notes, linked the way the poster visually threads them together.

## What this isn't

This is not a fact-checked reference work. The branch and sub-topic notes describe **what the map and its surrounding community claim**, not verified history or science. Where useful, notes include a short "Context" line noting the mainstream/evidentiary status of a claim. Treat this vault as a map of a *belief system and its internal logic*, not a map of established facts.

## Node labels are reconstructed, not traced

I don't have pixel-level access to the original poster, so the branch and sub-topic names here are built from public descriptions of the map's themes (deep state/cabal, ET disclosure, free energy, ancient civilizations, 5D consciousness, health sovereignty) rather than copied directly off the image. If you have the actual poster or a high-res scan, compare it against this structure and rename/add/remove notes to match — the vault is designed to be edited freely.

## Structure

- One hub note ([[The Great Awakening Map|index]]) links to six branch notes.
- Each branch note is a Map of Content (MOC) linking to 2 sub-topic notes.
- Sub-topic notes cross-link sideways to related topics in other branches (e.g. [[Secret Space Programs]] links to both its ET Disclosure branch and to [[Free Energy & Suppressed Technology]]).
- Tags (`#branch`, `#deep-state`, `#disclosure`, etc.) let you filter and re-cluster the graph inside Obsidian independent of the folder structure.

## Extending it

To add a new node: create a note, link it from at least one existing note with `[[Double Brackets]]`, and add relevant tags. Obsidian's graph view and Quartz's generated site will pick it up automatically — no manual index maintenance needed. test
